# BrevitySisterBot 0.3.0 — вординг и промпты

Этот файл генерируется из `content/bot_copy.ru.toml`. Не редактируйте
его вручную: измените TOML и снова запустите renderer.

## Контекст продукта и ограничения

- Бот делает сводки переписки подключённых Telegram-групп за текущий день.
- Автоматическая сводка требует минимум 15 сообщений и публикуется в 21:00 по
  Москве; ручная сводка по `/summary` требует минимум 5 сообщений.
- Ручной запрос работает и в группе, и напрямую в личном чате. Групповой
  результат видят все участники, личный — только запросивший пользователь.
- Выбор через нативный интерфейс Telegram или групповую deep link-ссылку проверяет доступ, после успеха запоминает группу и сразу начинает готовить сегодняшнюю личную сводку.
- Предварительно отправлять `/summary` в группе не требуется.
- Обычный `/start` в личном чате показывает приветствие с кнопкой и не запускает подготовку сводки.
- Кнопка под приветствием и `/summary` используют одну таблицу решений: если есть ровно одна запомненная доступная группа и это единственная подключённая группа бота, подготовка начинается сразу; при нескольких запомненных группах бот показывает их кнопки, иначе бот предлагает выбрать группу через нативный интерфейс Telegram.
- Подключать и отключать ежедневную публикацию может только администратор
  группы. Сам бот тоже должен быть администратором подключённой группы.
- После подключения бот публикует кнопку личного получения, но не закрепляет
  сообщение автоматически.
- Отключение ежедневной публикации не останавливает накопление сообщений и не
  отключает ручные сводки.
- Перед личной выдачей Telegram должен подтвердить членство пользователя.
- Подготовка может занимать до 2 минут; повторный запрос не ускоряет результат.
- Итог должен помещаться в одно Telegram-сообщение: максимум 3900 символов.
- Модель пишет только по фактам переписки, без домыслов, оценок и выдуманных
  решений, эмоций, консенсуса или важности темы.
- Команды, ключи TOML и переменные вида `{{variable}}` менять нельзя без
  соответствующего изменения интерфейса и кода.
- Тон: спокойный, понятный, человечный и лаконичный — без канцелярита,
  давления, фамильярности и лишних технических подробностей.

## Молчаливые сценарии

Бот намеренно ничего не отвечает:

- на неизвестную команду в группе;
- на обычное сообщение в личном чате;
- на обычное сообщение в неподключённой группе;
- после успешного сохранения обычного группового сообщения;
- когда автоматическая сводка пропущена из-за порога менее 15 сообщений.

Добавление ответа в любой из этих сценариев меняет поведение продукта и требует
отдельного решения, а не только редакторской правки.

## Готовый запрос для внешнего редактора

Скопируйте следующий запрос вместе с этим документом и исходным TOML:

```text
Ты UX-редактор Telegram-бота. Используй приложенный контекст показа и полный
TOML как единый источник текстов. Перепиши пользовательские сообщения,
шаблоны и LLM-промпты на естественном современном русском. Сохрани все факты,
команды, числа, ограничения, условия показа, названия секций и ключей, а также
все переменные вида {{variable}}. Сделай тон спокойным, дружелюбным и
лаконичным. Не добавляй функциональность. Улучши основной и резервный шаблоны,
а также промпты так, чтобы результат оставался фактическим, компактным и не
приписывал переписке отсутствующие решения, эмоции, консенсус или важность.
Верни полный валидный TOML без сокращений и без Markdown-обёртки. Комментарии
редактора помести после TOML отдельным списком.
```

## `messages`

### `messages.group_commands`

Контекст: Пользователь отправляет /start в группе.

```text
Команды: /enable_daily, /disable_daily, /summary
```

### `messages.daily_enabled`

Контекст: Администратор успешно отправил /enable_daily.

```text
Готово — ежедневные сводки включены. Буду публиковать их в 21:00 по Москве.

Хотите получить сегодняшнюю сводку лично? Нажмите кнопку ниже.
```

### `messages.daily_disabled`

Контекст: Администратор успешно отправил /disable_daily.

```text
Ежедневные сводки отключены. Сообщения продолжу собирать — сводку по-прежнему можно запросить командой /summary.
```

### `messages.group_not_connected`

Контекст: Участник вызывает /summary в неподключённой группе.

```text
Сначала администратор должен подключить группу через /enable_daily.
```

### `messages.admin_required`

Контекст: Не-администратор меняет настройку ежедневной сводки.

```text
Только администратор группы может менять настройки сводки.
```

### `messages.summary_accepted`

Контекст: Ручной запрос принят до обращения к модели.

```text
Запрос принят. Подготовка сводки может занять до 2 минут. Пожалуйста, не отправляйте команду повторно.
```

### `messages.summary_in_progress`

Контекст: Тот же набор сообщений уже обрабатывается.

```text
Сводка по этим сообщениям уже готовится. Повторять запрос не нужно.
```

### `messages.not_enough_messages`

Контекст: Для ручной сводки накоплено меньше пяти сообщений.

```text
Пока недостаточно сообщений для сводки. Нужно минимум 5 сообщений за сегодня.
```

### `messages.choose_group_native`

Контекст: В личном чате нет запомненной доступной группы.

```text
Выберите группу, для которой нужна сводка.
```

### `messages.choose_group_known`

Контекст: В личном чате доступно несколько групп.

```text
Из какой группы подготовить сводку?
```

### `messages.group_choice_expired`

Контекст: Одночасовой выбор группы недействителен.

```text
Этот выбор устарел. Отправьте /summary ещё раз.
```

### `messages.membership_not_confirmed`

Контекст: Telegram не подтверждает членство перед выдачей.

```text
Не могу выдать сводку: Telegram не подтверждает, что вы состоите в этой группе.
```

### `messages.bot_admin_required`

Контекст: Бот не администратор при /enable_daily.

```text
Чтобы подключить сводки, назначьте меня администратором группы и повторите /enable_daily.
```

### `messages.private_link_invalid`

Контекст: Групповая deep link-ссылка неизвестна или повреждена.

```text
Эта ссылка больше не работает. Выберите группу вручную.
```

### `messages.selected_group_not_connected`

Контекст: Выбранная через Telegram группа не подключена.

```text
В этой группе сводки ещё не подключены. Попросите администратора выполнить /enable_daily.
```

### `messages.group_access_unverifiable`

Контекст: Бот не может надёжно проверить выбранную группу.

```text
Не могу проверить доступ к этой группе. Попросите администратора назначить меня администратором.
```

### `messages.private_welcome`

Контекст: Обычный /start в личном чате: приветствие без запуска сводки.

```text
Привет! Я готовлю краткие сводки по сообщениям из подключённых групп. Нажмите кнопку ниже или отправьте /summary.
```

```text

{{topic_details}}
```

### `summary.topics_separator`

Контекст: Разделитель блоков тем.

```text



```

## `fallback`

### `fallback.document`

Контекст: DeepSeek недоступен, вернул ошибку или невалидный ответ; бот составляет детерминированную локальную сводку без интерпретации содержания.

```text
<b>📝 Краткая сводка за сегодня</b>

Сообщений за сегодня: {{message_count}}.
Активные участники: {{participants}}.
Последние обсуждавшиеся вопросы:
{{recent_messages}}
```

### `fallback.participants_unknown`

Контекст: Подстановка, когда участники не определены.

```text
не определены
```

### `fallback.message_item`

Контекст: Строка одного сообщения в локальной сводке.

```text
• {{message_text}}
```

### `fallback.messages_separator`

Контекст: Разделитель строк локальной сводки.

```text


```

## `prompts`

### `prompts.system`

Контекст: Системная инструкция суммаризатору.

```text
Ты редактор краткой сводки Telegram-группы. Пиши по-русски, строго по фактам из переписки, без домыслов и персональных оценок. Верни только JSON: {"headline":"главный итог дня","topics":[{"title":"тема","details":"конкретные итоги"}]}. Не более четырех тем.
```

### `prompts.user`

Контекст: Запрос с сегодняшней перепиской (последние 18 000 символов).

```text
Подготовь сводку сегодняшней переписки:

{{transcript}}
```

### `prompts.transcript_line`

Контекст: Формат одной строки переписки.

```text
[{{iso_datetime}}] {{participant_name}}: {{message_text}}
```

### `prompts.repair`

Контекст: Одна попытка исправления; первые 6000 символов ответа.

```text
Исправь ответ в требуемый JSON без добавления фактов:
{{invalid_model_response}}
```
